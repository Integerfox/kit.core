# Kit::Driver::Dio::ST::M32F4
@brief namespace description for Kit::Driver::Dio::ST::M32F4
@namespace Kit::Driver::Dio::ST::M32F4 @brief

The M32F4 namespace contains the STM32F4 HAL-based digital I/O driver 
implementations.  These drivers wrap the STM32 HAL GPIO functions into the
Kit::Driver::Dio interface(s).
