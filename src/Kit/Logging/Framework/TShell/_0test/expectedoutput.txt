log pkg
  Displays stored log records entries and Classification/Package Info. Records
  are always displayed newest entry first. The output format is:
  "[<entrykey>] (<entryTimestamp>) <PACKID>:<CATID>:<MSGID>. <text>"
  - 'log' with no arguments displays the newest entry.
  - 'log *'        displays all entries.
  - 'log <max>'    displays at most <max> entries.
  - 'log <skip> *'     skips the first <skip> entries, the displays all
                       remaining log entries.
  - 'log <skip> <max>' skips the first <skip> entries, then displays at most
                       <max> log entries.
  - 'log class' displays classifications IDs and mask status.
  - 'log pkg'   displays packages IDs and mask status.
