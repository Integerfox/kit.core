Detailed Description

This class implements the Flash::IApi interface for the Winbond W25Q series SPI NOR flash devices using standard (single-lane) SPI and 3-byte (24-bit) addressing.

It communicates with the flash device via an SPI driver and a chip select (CS) digital output pin.

The implementation handles page-boundary crossing for write operations, polls the BUSY status after each write/erase, and supports W25Q16 through W25Q128 devices.

NOTE: The driver does NOT clear the Block Protect (BP) bits. The caller must ensure the device is unprotected; otherwise program/erase operations are silently ignored by the device.

NOTE: This driver is intentionally scoped to Standard SPI operation and 3-byte addressing. QSPI and/or 4-byte addressing variants can be added as separate drivers that co-exist in this directory.
