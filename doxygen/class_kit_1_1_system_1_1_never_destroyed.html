Detailed Description

template<class T>
class Kit::System::NeverDestroyed< T >

Holds a lazily constructed, never destroyed instance of T.

Declare instances as function-local statics. Construction-on-first-use removes the static initialization order dependency for globals that are used from other translation units' static constructors.

This class MUST remain trivially destructible (see the static_assert below) - a non-trivial destructor on a function-local static is registered via atexit()/__cxa_atexit(), which pulls newlib's exit machinery (and the undefined '_fini') into the bare-metal targets.
