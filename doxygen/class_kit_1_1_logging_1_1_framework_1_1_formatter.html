Selects how the time portion of an entry's timestamp (see Kit::Time::getBootTime()) is rendered.

The timestamp's time portion is elapsed time since power-up unless the application has configured boot time to use absolute time (i.e. USE_KIT_TIME_BOOTTIME_WITH_ABSOLUTETIME)

Enumerator

UTC date/time, i.e.

the time is milliseconds since the Epoch: YYYY-MM-DD HH:MM:SS.mmm

eELAPSED 

Elapsed time, i.e.

the time is milliseconds since power-up: DD HH:MM:SS.mmm

Converts a binary EntryData_T struct instance to formatted text.

The application is responsible for ensuring the 'dstStringBuf' argument can contain the maximum formatted size (the default size is OPTION_KIT_LOGGING_FORMATTER_MAX_TEXT_LEN). The 'persistentStorageId' argument is optional and represents the persistent storage ID for the entry being converted. The 'timestampFormat' argument selects how the timestamp is rendered; it defaults to defaultTimestampFormat. The format shown below is the eABSOLUTE format; eELAPSED replaces YYYY-MM-DD HH:MM:SS.mmm with DD HH:MM:SS.mmm.

The method returns true when successful. False is returned if the provided string buffer was not large enough to hold the formatted entry.

The format is:
[<storageIdAsciiHex>] (<bootCnt>:YYYY-MM-DD HH:MM:SS.mmm) <appState><classification>-<packageId>-<subSystemId>-<msgId>: <messageText>
OR
(<bootCnt>:YYYY-MM-DD HH:MM:SS.mmm) <appState><classification>-<packageId>-<subSystemId>-<msgId>: <messageText>
Where <appState> is the Application's rendering of the entry's application
state (see IApplication::applicationStateToString()). By default this is
an empty string. The rendering is truncated to
OPTION_KIT_LOGGING_FORMATTER_APPLICATION_STATE_TEXT_LEN characters.

constexpr TimestampFormat_T Kit::Logging::Framework::Formatter::defaultTimestampFormat = TimestampFormat_T::KIT_LOGGING_FORMATTER_DEFAULT_TIMESTAMP_FORMAT_
staticconstexpr

The default timestamp format, i.e.

the format that matches the time source of Kit::Time::getBootTime(). USE_KIT_TIME_BOOTTIME_WITH_ABSOLUTETIME (defined in kit_config.h) is the source of truth: eABSOLUTE when it is defined, else eELAPSED.

NOTE: An application that provides its own getBootTime() (see USE_KIT_TIME_CUSTOM_GET_BOOT_TIME) that returns absolute time must also define USE_KIT_TIME_BOOTTIME_WITH_ABSOLUTETIME.
