23/** This concreate class implements a type safe MP for the data structure: Foo_T
24
25 The toJSON() format is:
26 ```
27 { name:"<mpname>", type:"<mptypestring>", valid:true|false, seqnum:nnnn, locked:true|false,
28 val: {
29 "upper":nnnn, "lower":nnnn, "result":nnnn, "isValid":true|false
30 }
31 }
32 ```
33
34 The "val" format for the fromJSON() format is:
35 ```
36 val: {"upper":nnnn, "lower":nnnn, "result":nnnn, "isValid":true|false }
37 ```
38
39 NOTES:
40 - The parent class (Kit::Dm::Mp::Scalar) provides the implementation
41 for all of the standard MP operations (e.g. read, write, attachObserver,
42 detachObserver, etc).
43
44 - The MpFoo class must provide the toJSON() and fromJSON() methods for the
45 Foo_T structure
46
47 - The MpFoo class provides additional "write" operations to enforce its
48 intended transaction paradigm.
49
50 - The toJSON() method supports only updating the specified/included KVPs,
51 e.g. "val":{"upper":12}" - is a read/modify operation that only updates
52 the 'upperLimit' field of the MP's data structure.
53
54*/
