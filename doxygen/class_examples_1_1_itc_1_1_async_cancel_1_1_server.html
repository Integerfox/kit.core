Detailed Description

This concrete class is a 'server' that produces the LED flash patterns.

The server accepts flash requests from many clients. The server responses to a client AFTER it has completed the client's requested duty cycles. Flash requests are queued in FIFO order. A software timer is used to manage the LED flashing.
