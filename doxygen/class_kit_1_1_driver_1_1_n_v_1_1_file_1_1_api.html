Detailed Description

This class implements the Non-volatile storage driver using the Kit::Io::File interfaces.

The storage is a single file. When the driver is started, the file is created if it does not exist, and a file that is shorter than the storage size is padded (at its end) up to the storage size with OPTION_KIT_DRIVER_NV_FILE_ERASED_VALUE, i.e. existing content is preserved. A file that is longer than the storage size is accepted as-is, and only the first getTotalSize() bytes are used. This allows the application to change the storage size between releases, and it completes the initialization of a file whose padding was interrupted (e.g. a failed start() or a power loss).

Because the Kit::Io::File interfaces use Kit::Type::SSize_T for offsets and byte counts, the driver fails to start if the total storage size exceeds the maximum value of Kit::Type::SSize_T.

The interface itself is NOT thread safe. It is the responsibility of the users/clients of the driver to handle any threading issues.

This method allows the client to change the filename that was specified via the constructor.

This method will FAIL if called when the driver is in its 'running' state.

NOTE: Just the like constructor parameter, the filename is NOT copied; the caller is responsible for ensuring that the string remains valid while the driver is being used.
