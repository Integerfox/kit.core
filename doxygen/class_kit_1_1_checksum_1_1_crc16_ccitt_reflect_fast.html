Detailed Description

This class provides an implementation for the 16 Bit CRC-CCITT standard (with reflection).

The CRC has following characteristics (aka CRC-CCITT(0xFFFF)): o The polynomial is x16 + x12 + x5 + 1 o The Data bytes ARE reflected o The remainder IS reflected. o The final remainder is NOT XOR'd
