Detailed Description

This class defines the interface for a digital output pin.

The interface operates on the LOGICAL state of the output, abstracting away the physical polarity (active-high vs active-low). When the output is 'asserted', the pin is in its logically active state regardless of the underlying electrical polarity.

The interface itself is NOT thread safe. It is the responsibility of the users/clients of the driver to handle any threading issues.
