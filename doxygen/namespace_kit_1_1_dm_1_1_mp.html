This enumeration defines the status of a request.

Parameters
RunRequestStatusEnum
NOPNo operation request, i.e. the initial state before any request has been made
PENDINGThe request is in-flight, i.e. waiting for the widget's response
COMPLETEDThe request was completed successfully
NOT_SUPPORTEDThe requested transition is not supported by the widget
FAILEDAn error occurred while attempting the transition
NOT_ACCEPTEDThe current state does not allow a transition to the requested state, e.g. the widget is in the ERRORED state or the data Model Point is in the invalid state (i.e. the widget's state has not been published)
ERR_REQUEST_IN_PROGRESSA request is already in progress. This value is ONLY returned to the requestor, i.e. it is NEVER stored in the Model Point
