21/** This class provides the 32 Bit CRC used by the DMTF PLDM standard (e.g. the
22 PLDMVersionData integrity checksum). It is a distinct type, but it adds
23 nothing to Crc32EthernetFast, i.e. Crc32EthernetFast is the source of
24 truth for the implementation.
25
26 DSP0240 (PLDM Base Specification, v1.0.0) specifies:
27 o The polynomial is the same as the one used by IEEE 802.3 (0x04C11DB7)
28 o Each byte is processed least significant bit first, i.e. the data
29 bytes and the remainder are reflected
30 o The checksum is a uint32 field, i.e. it is Little Endian (the
31 default PLDM byte ordering) in the 'destBuffer'
32
33 DSP0240 does NOT specify the initial remainder or the final XOR value.
34 The standard CRC-32 values are used (and are what PLDM implementations
35 use): the initial remainder is 0xFFFFFFFF, and the final remainder is
36 XOR'd with 0xFFFFFFFF. These are exactly the characteristics of
37 Crc32EthernetFast, including its Little Endian 'destBuffer' encoding.
38 The CRC value for the text string "123456789" is 0xCBF43926.
39
40 https://www.dmtf.org/sites/default/files/standards/documents/DSP0240_1.0.0.pdf
41 */
