Detailed Description

This class provides a CRC8 "SMBus" algorithm using a table look-up.

The CRC has following characteristics: o The polynomial is x8 + x2 + x + 1 (0x07) o The initial remainder is 0x00 o The Data bytes are NOT reflected o The remainder is NOT reflected. o The final remainder is NOT XOR'd
