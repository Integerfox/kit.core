26/** This template class provides the common infrastructure for 'pseudo' Model
27 Points, i.e. a Model Point that provides a role-specific view (e.g. the
28 RunRequestor and RunManager classes) of a 'data' Model Point.
29
30 A pseudo Model Point is registered in the Model Database under its own name
31 (so that it can be accessed via JSON), but it has no data of its own. Its
32 state - validity, sequence number, locked state, data size (getSize()),
33 and toJSON() output - is that of the data Model Point. Only the pseudo
34 Model Point's public 'writer' methods can modify the data Model Point. As
35 such, the following generic operations are NOT supported (i.e. they do
36 nothing): setInvalid(), setLockState(), touch(), exportData(), and
37 importData(). In addition, setJSONVal() is not supported (it always returns
38 false), but toJSON() is delegated to the data Model Point.
39
40 Template Arguments:
41 ELEMTYPE - The type of the data Model Point's data
42 MPTYPE - The concrete data Model Point type. The type must provide
43 the type safe read(), attach(), and detach() methods
44 (e.g. be derived from Kit::Dm::Mp::Scalar)
45
46 IMPORTANT: A pseudo Model Point is transient/run-time state and MUST NEVER
47 be persistently stored.
48
49 NOTE: All methods in this class ARE thread Safe unless explicitly
50 documented otherwise.
51 */
