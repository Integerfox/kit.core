Detailed Description

Data stored by the RunControl Model Point.

The following are needed because the structure is used as a 'data source'

for a Model Point:

  • The comparison operation
  • The constructors, copy constructor, and copy operator are implemented to ensure that any 'pad' bytes in the structure get zero'd out. This is desired because the default 'comparison operation' in the DM framework uses memcmp.

uint16_t Kit::Dm::Mp::RunControl_T::requestId

Identifier of the most recent request.

The identifier is incremented for each new request (and never zero once a request has been made), i.e. it allows a requestor to correlate a result with its request even when change notifications have been coalesced.
