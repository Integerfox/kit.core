69/** This concrete class provides the implementation of Command Processor for
70 a TShell engine.
71
72 The implementation assumes a single threaded model, i.e. the Command
73 Processor and all of its commands run in a single thread. It is
74 APPLICATION's responsibility to provide any desired multi-threaded
75 support. There are two caveats to the single-threaded model:
76
77 o The output of the commands are mutex protected. This allows the
78 Output stream to be 'shared' with other sub-systems and/or
79 threads (e.g. the shell shares the same Output stream as the
80 Kit::System::Trace logging output).
81
82 o The stop() method can be called safely from other threads.
83
84
85 Commands have the following syntax:
86
87 o A command starts with a printable ASCII character and ends with
88 a newline.
89
90 o Non-printable ASCII characters are not allowed.
91
92 o Any line that starts with a '#' is treated as comment line and
93 is ignored.
94
95 o Format of a command is: verb [arg]* where the verb and arguments
96 are separated by spaces. Arguments can contain spaces character
97 by enclosing the argument with double quote characters. A double
98 quote character can be embedded inside a quoted string by preceding
99 it the double quote character with the escape character. The escape
100 character can be embedded by escaping the escape character.
101
102 HOW TO Enable Security:
103
104 - Set OPTION_KIT_TSHELL_SECURITY_DEFAULT_PERMISSIONS to something
105 other than zero. This is the default constructor value for all KIT
106 TShell commands.
107
108 - Provide an implementation (other than `NoSecurity`) of the ISecurity
109 interface that meets the application's security requirements.
110*/
111class Processor : public IProcessor, public IContext

114 /** Constructor.

122 @param securityPolicy Security policy for the shell commands.
123 @param outputLock Mutex to be used for ensuring the atomic output
124 of the commands.
125 @param convertTabs If set to a value other than a tab character, then
