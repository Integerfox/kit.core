Detailed Description

This class provides the 'manager' side of a RunControl Model Point, i.e.

the interface for the owner of a 'runnable' widget to receive requests (from a RunRequestor), respond to the requests, and maintain the widget's actual state.

The owner of the RunManager instance determines the request's status, i.e. the class does not decide whether a transition is supported or allowed. The following guidelines are recommended so that all widgets behave consistently:

  • A repeated request, i.e. a request for the state the widget is already in (e.g. STOP when STOPPED) is responded to with COMPLETED.
  • A transition that the widget never supports is responded to with NOT_SUPPORTED.
  • A transition that is not allowed from the current state is responded to with NOT_ACCEPTED.
  • A transition that was attempted, but encountered an error, is responded to with FAILED (and, when the widget cannot continue, the ERRORED state).

The class enforces the following policies:

  • A response must match the in-flight request (identified by its request identifier), and must be a final status (not NOP/PENDING/ERR_REQUEST_IN_PROGRESS).
  • The ERRORED state is terminal, i.e. once in the ERRORED state the actual state cannot be changed.

The RunControl Model Point is invalid until setState() is called the first time. The owner is responsible for responding to every request; the class does NOT time-out requests.

The toJSON() output is that of the RunControl Model Point. The fromJSON() format only supports the writer methods:

val:{state:"<RunState>"} // setState()
val:{id:nnnn, status:"<RunRequestStatus>", newState:"<RunState>"} // respond()
The two forms use different keys so that they cannot be confused, i.e.
the keys cannot be mixed.
Examples:
{ name:"mp_runManager", val:{state:"STOPPED"} }
{ name:"mp_runManager", val:{id:1, status:"COMPLETED", newState:"RUNNING"} }

IMPORTANT: This (pseudo) Model Point is transient/run-time state and MUST NEVER be persistently stored.

NOTE: All methods in this class ARE thread Safe unless explicitly documented otherwise.
