25/** This class provides the 'manager' side of a RunControl Model Point, i.e.
26 the interface for the owner of a 'runnable' widget to receive requests (from
27 a RunRequestor), respond to the requests, and maintain the widget's actual
28 state.
29
30 The owner of the RunManager instance determines the request's status, i.e.
31 the class does not decide whether a transition is supported or allowed.
32 The following guidelines are recommended so that all widgets behave
33 consistently:
34 - A repeated request, i.e. a request for the state the widget is already
35 in (e.g. STOP when STOPPED) is responded to with COMPLETED.
36 - A transition that the widget never supports is responded to with
37 NOT_SUPPORTED.
38 - A transition that is not allowed from the current state is responded
39 to with NOT_ACCEPTED.
40 - A transition that was attempted, but encountered an error, is responded
41 to with FAILED (and, when the widget cannot continue, the ERRORED
42 state).
43
44 The class enforces the following policies:
45 - A response must match the in-flight request (identified by its
46 request identifier), and must be a final status (not NOP/PENDING/ERR_REQUEST_IN_PROGRESS).
47 - The ERRORED state is terminal, i.e. once in the ERRORED state the
48 actual state cannot be changed.
49
50 The RunControl Model Point is invalid until setState() is called the first
51 time. The owner is responsible for responding to every request; the
52 class does NOT time-out requests.
53
54 The toJSON() output is that of the RunControl Model Point. The fromJSON()
55 format only supports the writer methods:
56 \code
57
58 val:{state:"<RunState>"} // setState()
59 val:{id:nnnn, status:"<RunRequestStatus>", newState:"<RunState>"} // respond()
60
61 The two forms use different keys so that they cannot be confused, i.e.
62 the keys cannot be mixed.
63
64 Examples:
65 { name:"mp_runManager", val:{state:"STOPPED"} }
66 { name:"mp_runManager", val:{id:1, status:"COMPLETED", newState:"RUNNING"} }
67
68 \endcode
69
70 IMPORTANT: This (pseudo) Model Point is transient/run-time state and MUST
71 NEVER be persistently stored.
72
73 NOTE: All methods in this class ARE thread Safe unless explicitly
74 documented otherwise.
75 */
