39/** This class implements the Flash::IApi interface for the Winbond W25Q
40 series SPI NOR flash devices using standard (single-lane) SPI and 3-byte
41 (24-bit) addressing. It communicates with the flash device via an SPI
42 driver and a chip select (CS) digital output pin.
43
44 The implementation handles page-boundary crossing for write operations,
45 polls the BUSY status after each write/erase, and supports W25Q16
46 through W25Q128 devices.
47
48 NOTE: The driver does NOT clear the Block Protect (BP) bits. The caller
49 must ensure the device is unprotected; otherwise program/erase
50 operations are silently ignored by the device.
51
52 NOTE: This driver is intentionally scoped to Standard SPI operation and
53 3-byte addressing. QSPI and/or 4-byte addressing variants can be
54 added as separate drivers that co-exist in this directory.
55 */
