Detailed Description

This class extends IApi interface so that all write operations are verified by reading back the data after the write.

In addition, the class supports retrying write operations N time when there is read-back failure.

The interface itself is NOT thread safe. It is the responsibility of the users/clients of the driver to handle any threading issues.

◆ postWrite()

virtual bool Kit::Driver::NV::WriteWithVerify::postWrite ( bool writeResult)
protectedvirtualnoexcept

Hook that is called after the write operation.

'writeResult' is the result of the write (and read-back verification) attempts, and is false when preWrite() returned false. The return value is the result of the write() call - except when preWrite() returned false, in which case the write() call always fails. Default is NOP/return 'writeResult'.

protectedvirtualnoexcept

Hook that is called before the write operation (i.e.

before any write/retry attempts). Returning false fails the write operation without writing any data. Every call to preWrite() is paired with a call to postWrite() - even when preWrite() returns false - so that a child class can use the hooks to bracket the write operation (e.g. disable/enable write protection). Default is NOP/return true.
