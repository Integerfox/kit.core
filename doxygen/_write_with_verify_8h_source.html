33/** This class extends IApi interface so that all write operations are verified
34 by reading back the data after the write. In addition, the class supports
35 retrying write operations N time when there is read-back failure.
36
37 The interface itself is NOT thread safe. It is the responsibility of
38 the users/clients of the driver to handle any threading issues.
39 */

43 /** Constructor. 'numRetries' is the number of times a failed write (or

46 (the constructor asserts on violations).
47 */
48 WriteWithVerify( IApi& nvDriver, uint8_t numRetries = 0 ) noexcept;
