Detailed Description

This abstract class defines a stop operation that is intended to stop and/or shutdown a driver.

Once a driver has been stopped, it can be restarted by calling the its IStart interface.

Note: It is possible for a concrete driver class to implement more than one abstract driver interfaces. This use case introduces the classic C 'diamond' inheritance problem. The diamond inheritance is resolved by requiring each abstract driver interface to use 'virtual' inheritance when inheriting from IStop. This ensures that there is only one stop() method in the concrete child classes

This method stops the driver.

The stopped 'state' is platform specific. Once a driver has been stopped it can be restarted by calling its IStart interface.

Note: Calling stop() on an already stopped driver has no effect.
