Detailed Description

This class implements the Non-volatile storage driver using a collection of NV drivers to provide a 'flat address' space that spans multiple discrete storage chips/media.

The individual drivers/nv-storage-instance can be different sizes and different physical media.

The interface itself is NOT thread safe. It is the responsibility of the users/clients of the driver to handle any threading issues.

Kit::Driver::NV::Gang::Gang ( IApi * drivers[],
unsigned numDrivers )
noexcept

Constructor.

The 'drivers' argument is an array of pointers to concrete NV drivers and 'numDrivers' is the number of elements in the array. The array must contain at least one driver and none of the array elements can be a nullptr (the constructor asserts on violations). The array is NOT copied, i.e. it must remain valid for the lifetime of the Gang instance. The constructor does not access the drivers themselves.

size_t Kit::Driver::NV::Gang::getNumPages ( ) const

See Kit::Driver::NV::IApi.

The number of pages is based on the smallest page size from the various ganged drivers that fits within the total available space. When the ganged drivers have pages size that are not multiples of each other, the returned value can be just approximate number of pages.

overridevirtualnoexcept

See Kit::Driver::NV::IApi.

The reported page size is the smallest page size from the various ganged drivers. The value is calculated on demand, i.e. it is not cached, and is only valid while the instance is started (returns zero when the instance is stopped).
