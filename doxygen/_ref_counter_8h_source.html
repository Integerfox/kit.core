24/** This class provides a concrete implementation for a Point who's data is 32
25 bit unsigned reference counter. A reference counter can be increment or
26 decremented. When incremented, the value is clamped at 2^32 -1 (not allowed
27 to overflow). When decremented, the value is clamped at zero (not allowed
28 to underflow). In addition, change notifications are only generated on the
29 following transitions:
30
31 1) Invalid state to the Valid state
32 2) Valid state to the Invalid state
33 3) Transition to zero
34 4) Transition from zero to value greater than zero
35
36 Specifying ChangeNotice_T::eFORCE on an update operation generates a change
37 notification regardless of the above transitions.
38
39 The toJSON() format is:
40 \code
41
42 { name:"<mpname>", type:"<mptypestring>", valid:true|false, seqnum:nnnn, locked:true|false,
43 val:<numvalue>
44 }
45
46 \endcode
47
48 The "val" format for the fromJSON() format is:
49 \code
50
51 val:"[<act>]<numvalue>
52 where <act> can be:
53 "+" -->increment the counter
54 "-" -->decrement the counter
55 (no prefix) -->reset the counter to the specified value
56
57 Examples:
58 { name:"mp_visitors", val:"+2" } // Increments the point by 2
59 { name:"mp_visitors", val:"-1" } // Decrements the point by 1
60 { name:"mp_visitors", val:0 } // Resets the counter to zero
61
62 \endcode
63
64 NOTE: All methods in this class ARE thread Safe unless explicitly
65 documented otherwise.
66 */
