Detailed Description

Concrete half-duplex SPI driver for the STM32F4 HAL using polling mode.

Wraps the STM32 HAL SPI functions (HAL_SPI_Transmit, HAL_SPI_Receive) into the Kit::Driver::SPI::IHalfDuplex interface.

The 'spiHandle' must be a pointer to a fully initialized SPI_HandleTypeDef (e.g., &hspi3 from CubeMX).

The caller is responsible for managing the SPI chip select (CS) pin externally via a Dio::IOutput driver.
