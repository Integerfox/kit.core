Detailed Description

This partial concrete class provides common implementations, utility methods, etc.

for concrete child classes that implement the IChunk interface. The class ASSUMES the following:

  • All child classes will use a checksum to detect corrupted data.
  • There is sufficiently large temporary buffer to hold a Record's data plus ALL of the chunk's meta data (i.e. the entire chunk is assembled in the buffer so it can be transferred with a single IMedia call). Note: The private_.h header file provides a default buffer. See private_.h for additional details about the default buffer.
  • Some of helper methods (e.g. pushToRecord() and pullFromRecord()) are virtual wrapper methods. By having a virtual wrapper - pushing/pulling to/from the data record facilitates future child classes to extend existing chunk classes with the ability to decrypt/encrypt the record data

protectednoexcept

Helper method that reads an entire chunk (header + record data + EDC) from 'media' at 'index' into m_workBuffer and validates its EDC.

The chunk layout in m_workBuffer is: 

[header: 'headerLen' bytes][record data: 'dataLen' bytes][EDC]

The LAST field of the header MUST be the Size_T record data length.

The 'expectedDataLen' is used to read the entire chunk with a SINGLE IMedia::read() call. Additional reads are only issued when the stored data length is larger than 'expectedDataLen', or when the single read fails (e.g. the media is shorter than the expected chunk length).

Returns true and sets 'dataLen' if the chunk is valid; else false is returned. NOTE: m_workBuffer is overwritten, i.e. any previous chunk (or pointers into it) are invalidated.

bool Kit::Persistence::Record::Chunk::Common::writeChunk ( IMedia & media,
Size_T index,
Size_T len,
bool invalidate )
protectednoexcept

Helper method that computes the EDC over the first 'len' bytes of m_workBuffer (i.e.

header + record data), appends the EDC to the buffer, and then writes the entire chunk to 'media' at 'index' with a SINGLE IMedia::write() call. When 'invalidate' is true, the EDC is corrupted. The caller is required to ensure that 'len' plus the EDC size does not exceed m_workBufferSize. NOTE: The EDC bytes are written into m_workBuffer immediately after the first 'len' bytes.

Returns true if the write was successful, else false is returned.
