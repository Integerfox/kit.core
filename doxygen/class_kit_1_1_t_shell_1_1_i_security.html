Detailed Description

This abstract class defines the interface validating that is okay to execute a TShell command.

The underlying security model is specific to the application and is not defined by this interface.

pure virtualnoexcept

This method evaluates the current security state and returns true/false if the specified permission level is sufficient to execute a command.

The 'queryOnly' parameter is used to indicate that the caller is only interested in querying the security state and not actually executing the command. A use case for this is the TShell 'help' command that only displays authorized commands but does not execute them.

◆ isSilent()

virtual bool Kit::TShell::ISecurity::isSilent ( )
pure virtualnoexcept

This method is used to suppress the TShell outputs until the session has been 'authenticated'.

This can be useful in scenarios where you want to prevent unauthorized users from seeing certain output until they have successfully authenticated. The outputs that are suppressed - when the method returns true - include, but are not limited to, the following: 

- The TShell prompt
- The TShell welcome and farewell messages
- The TShell command error messages (e.g. unrecognized command, bad
  syntax, etc.)

NOTE: Output generated by individual commands (i.e. via the IContext's writeFrame() method) is NOT automatically suppressed by this method. It is the responsibility of individual commands to check the security state (via isSilent()) and suppress their output as needed.

Implemented in Kit::TShell::NoSecurity.
